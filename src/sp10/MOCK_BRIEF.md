# Brief — complete one 80-mark Class 10 (2026-27) MOCK paper, and generated gap-fill questions

Read `src/sp10/BRIEF.md` first (schema, chapter ids in `src/sp10/chapters.py`, KaTeX rules, validate.py). The 55 typed sample papers are in `src/sp10/data/<Subject>_<Paper>.json`; study the CBSE_Official and a few others to learn the real paper's style, difficulty, wording, how case/source items and assertion-reason items are built, and which chapters appear where. The owner's guess about the real exam: 20-30% of marks from NCERT-textbook-type questions, 30-40% straight from papers like these, the rest related to / versions of these questions. We train the mock papers the same way.

## A. Mock paper: `src/sp10/data/Mock_<Subject>_<NN>.json`  (already prefilled; edit in place)
The file keeps the official paper's structure (question numbers, sections, marks, types). Each question has `origin`:
- `real` — a real sample-paper question, already copied in (`basis` says which). Do NOT change it (you may fix an obvious typo).
- `variant` — `basis_question` holds a real sample question. Write a NEW question of the same type, marks, chapter and difficulty with changed values / names / context / numbers (and a different final answer), solving it fully and checking the arithmetic in Python. For assertion-reason, MCQ, case-based etc. keep the same format. For English/Hindi: new passage/extract/topic of the same kind, not the same text.
- `ncert` — write an original NCERT-exercise-style question for the slot's `chapter` with the slot's type/marks (the kind of question a textbook exercise or example gives; fresh numbers/context; no verbatim textbook text). For English/Hindi literature: a question on that lesson/poem that tests the typical points (theme, character, extract, vocabulary, figure of speech), original wording.
Fill `text`, `options` (4 for mcq/ar), `answer` (with working and marks split where the paper style has it), `subparts` (case/passage/extract questions, with per-subpart marks/options/answers), `figure` stays null (no diagrams: phrase geometry questions so no figure is needed, or describe the figure in words; for map questions write a location-identification question without a map, i.e. type `vsa`/`sa`... only if the slot is a map slot keep type `map` and ask students to mark/locate on "a blank outline map of India" with the expected answer in the key). Keep `origin`, `basis`, `chapter`, `marks`, `type`, `section`, `no` exactly; set `"or"` when the slot's official counterpart has an internal choice (give an alternative of equal marks, same chapter group).
Difficulty/wording must feel like the real 2026-27 paper (competency-based, application, case-based, AR) — study it. Answers must be correct: recompute every number; for factual (SST/Science/English/Hindi) answers use only facts you are certain of from the NCERT textbook; where unsure choose another question.
Check: marks sum to 80, MCQs have exactly one correct option, no duplicate of an existing sample question, chapter ids valid. Run `python src/sp10/validate.py <file>`.

## B. Gap-fill (only if your task says so): `src/sp10/data/Gen_<Subject>_<tag>.json`
Same schema as a paper file (`"paper":"Gen"`) with questions numbered 1.. and for each: `chapter` (exact id), `type`, `marks`, `section` (use "A".."E" by marks like the paper), `origin` (`ncert` | `variant` | `related`) and `basis` (e.g. "SP03 Q12" for variants). Mix per chapter about 30% ncert-style, 40% variants of existing sample questions of that chapter (changed values/context), 30% related questions (same concept, new angle). Use the type/marks mix the real paper uses for that chapter (MCQs 1, VSA 2, SA 3, LA 5, case 4, AR 1). No figures.
